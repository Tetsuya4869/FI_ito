基礎 小テスト（自己診断）

基礎6分野から10問。8問以上正解なら上級分野へ進む準備OK。間違えた分野のページに戻って復習しましょう。

自己診断選択式10問
💡 使い方

全問に答えて「採点する」を押すと、正誤と復習先が表示されます。採点はブラウザ内で完結し、記録は保存されません。

Q1$f(x)=x^3$ の導関数 $f'(x)$ は？

✓ 正解。$（x^n)' = nx^{n-1}$。
✗ 不正解。正解は $3x^2$（べきの微分 $(x^n)'=nx^{n-1}$）。復習:

Q2$\displaystyle\int_0^1 x^2\,dx$ の値は？

✓ 正解。$[x^3/3]_0^1 = 1/3$。
✗ 不正解。原始関数 $x^3/3$ の差で $1/3$。復習:

Q3$\mathbf{a}=(1,2)$、$\mathbf{b}=(3,-1)$ の内積 $\mathbf{a}\cdot\mathbf{b}$ は？

✓ 正解。$1\cdot3 + 2\cdot(-1) = 1$。
✗ 不正解。成分ごとの積の和 $3-2=1$。復習:

Q4$A=\begin{pmatrix}3&0\\0&5\end{pmatrix}$ の固有値は？

✓ 正解。対角行列の固有値は対角成分。
✗ 不正解。対角行列の固有値は対角成分そのもの（$3$ と $5$）。復習:

Q5$\lnot(\forall x,\ P(x))$ と同値なのは？

✓ 正解。「すべて成り立つ、の否定」＝「成り立たない例がある」。
✗ 不正解。全称の否定は存在＋否定（反例の存在）。復習:

Q6$A=\{1,2,3\}$、$B=\{2,3,4\}$ のとき $A\cap B$ は？

✓ 正解。両方に属する要素。
✗ 不正解。共通部分は「両方に属する」要素で $\{2,3\}$。復習:

Q7公平なコイン1回の表の枚数 $X$（表=1, 裏=0）の期待値は？

✓ 正解。$E[X]=1\cdot\frac12+0\cdot\frac12=\frac12$。
✗ 不正解。$E[X]=1\cdot\frac12+0\cdot\frac12=\frac12$。復習:

Q8事象 $A,B$ が独立であるための条件は？

✓ 正解。独立＝積の法則が成り立つこと。
✗ 不正解。独立の定義は $P(A\cap B)=P(A)P(B)$（排反とは別概念）。復習:

Q9質量 $4\,\text{kg}$ の物体に $12\,\text{N}$ の力を加えたときの加速度は？

✓ 正解。$a=F/m=12/4=3$。
✗ 不正解。$F=ma$ より $a=F/m=3\,\text{m/s}^2$。復習:

✓ 正解。$K=\frac12mv^2$。
✗ 不正解。運動エネルギーは $\frac12 mv^2$。復習:
